# OpenSpec Calculator

Modern AI-styled calculator application built using Python Flask and Spec Driven Development workflow.

---

## Features

- Modern Glassmorphism UI
- Clickable Calculator Buttons
- Keyboard Support
- Calculation History
- Clear History Button
- Responsive Design
- AI Styled Frontend
- Flask Backend
- YAML Specifications

---

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- YAML

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run Flask app:

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```
